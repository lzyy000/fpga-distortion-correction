# R21 相机上位机

从工程根目录 `06_相机上位机.cmd` 启动。工具和连接配置见 [工程 README](../../README.md)。

- 串口连接后，“算法调节”页独立控制矫正、双视窗、滤波和夜景；滤波、夜景开启后显示各自强度滑条。
- 双视窗左侧始终是原始图像，右侧体现处理；模式控制需要 R21 位流和串口确认。
- 网口照片为完整 1920×1080 RGB565 单幅图像，包含滤波和夜景效果，不包含分屏布局与矫正几何；通过完整收包和 CRC 校验后保存 PNG 和元数据。
- 电脑 192.168.1.105，板卡 192.168.1.11，双方 UDP 8080；串口 115200 波特。
- 照片目录在 `settings.json` 配置，当前照片和标定数据保留。棋盘为 9×6 内角点、25mm；上位机计算候选标定参数后不会自动写入 FPGA。
- 测试中的旧版本握手、强度回复用于 R21 兼容性回归，不代表目录中仍有旧版活动工程。

当前 R21 最终时序未通过；网口曾在 KEY0 复位后恢复连接，完整实板组合验收尚未完成。详见 [R21 操作与协议](../../docs/R21_HOST_MODES.md)。
