# R19 强度控制协议

串口115200、8N1。上位机先查询能力，只在收到正确的 R19 TUNE 回复后启用滑条；连接旧位流不会自动改动算法状态。图像仍通过原CNP1网口协议回传。

| 单字节命令 | 含义 |
|---|---|
| 0xF0 | 查询夜景/滤波百分比、Q8参数及按键请求状态 |
| 0x80～0xE4 | 设置夜景0～100%，值为命令减128 |
| 0x00～0x64 | 设置滤波0～100%，值为命令本身 |
| 0x6E，即小写n | 保留原网络诊断查询 |

这是二进制参数协议，不要把滑条数值当文本输入串口。大写N（0x4E）落在滤波设置区，不再作为网络诊断快捷字符。

例：夜景50%发送单字节0xB2，滤波50%发送0x32。百分比转换为Q8：`(percent*256+50)/100` 的整数商。

回复为一条ASCII行，CRLF结束：

```
TUNE v=19 cmd=000000B2 night=50 denoise=100 night_q8=128 denoise_q8=256 night_on=0 denoise_on=0
```

`cmd`回显命令；百分比与Q8均须匹配。回复表示配置寄存器已写入并回读；当前帧不会中途改参，新帧应用参数。`night_on`、`denoise_on`为KEY4、KEY3请求状态，不是软件开关。

上位机同一时刻只等待一条命令确认，拖动变化合并150ms，确认超时1.5秒，同一条最多发送3次；设置为绝对值，重试不会反复切换开关。超时后禁用滑条并明确提示重新连接。每2秒查询一次状态；重新连接先读取板卡值，不自动覆盖。板卡复位横幅出现后清除待发设置并重新查询。

硬件CTRL寄存器基址沿用R18：偏移216为夜景Q8请求值，220为滤波Q8请求值，均接受完整32位写、范围0～256；224低9位为当前输入帧夜景强度、位24:16为滤波强度。偏移200读出0x52313953。KEY3/4开关寄存器不开放软件写入。

空间滤波参数在流处理器frame_start提交，此时上一帧包括底部复制行和新增混合流水线均已排空。时域DMA在每帧首块单独冻结强度；夜景强度跟随捕获槽保存，矫正与HDMI读取同一槽元数据。HDMI同步和DE随6拍处理延迟对齐。
