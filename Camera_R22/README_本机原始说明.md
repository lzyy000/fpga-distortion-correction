## 操作入口

1. `00_本机预检.cmd`：检查 PDS、许可证路径、工具链、依赖和必要工程文件，不编译 FPGA。
2. `06_相机上位机.cmd`：启动 R22 上位机。连接 USB_UART 后选择 CP210x 端口，波特率 115200。
3. `01_打开工程.cmd`：打开 `D:\pango\pango100Pro\Camera_R22_20261031\pnr_camera_r21_modes\camera_1080p30_raw8.pds`。目录和工程名沿用 R21，但活动顶层是 R22 融合设计。预检、打开和构建入口会检查 PDS 允许的目录字符。
4. `04_离线验证.cmd`：有限 RTL、CPU、鱼眼、旋转稳像和上位机回归，不启动 PDS。
5. `05_核对发布.cmd`：核对当前源码、ROM、标定和缓存边界。成功只代表输入一致；以终端输出区分 SOURCE ONLY 和已重建位流。
6. `02_重新编译.cmd`：用户需要新位流时运行，执行固件、离线检查、PDS 综合至位流和当前构建时序核验。

上位机自检可运行 `06_相机上位机.cmd -SmokeTest`，创建界面后自动关闭，不连接设备。
`01_打开工程.cmd -CheckOnly`、`02_重新编译.cmd -CheckOnly` 仅检查入口。
`03_串口测帧率.cmd` 默认只读采集 60 秒；现已识别 R21/R22 并在报告中记录实际身份。先关闭占用串口的程序，必要时加 `--port COM实际编号`，采集期间按 KEY0 取得完整启动信息。没有本轮启动身份/寄存器回读时不会宣称验收通过。
