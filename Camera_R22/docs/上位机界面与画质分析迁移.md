# 上位机界面与图像质量分析迁移

2026-10-30。参考用户提供的 `R29_Host_Portable_20261030_202517` 源码界面及独立质量模块，适配当前 R22 控制器。没有迁入 R29 串口协议、分源抓拍协议或平面透视控制。

## 打开和验证

- 仍用根目录 `06_相机上位机.cmd` 打开。已运行的旧窗口需要关闭后重新打开，源码更新不会改变旧进程的界面。
- `32_验证上位机界面与画质.cmd`：离线上位机回归、合成图卡测量、MTF 导出和源码/ROM 核对；不连接真实板卡，不运行 FPGA 构建。
- `console.py --ui-preview --geometry 1060x720`：不自动发现设备、不写连接设置的界面检查。

## 保留的功能

原有串口监测、四项帧率指标、网络配置、完整帧抓拍、补包、CRC、取消、原尺寸 PNG 保存、9×6 / 25mm 棋盘检测与标定候选计算保留。八项算法仍由原 `StrengthControl` 和现有固件确认：Brown 畸变矫正、双视窗、滤波、夜景、全局直方图均衡、IMU 小抖动防抖、鱼眼畸变处理、旋转稳像。Brown / 鱼眼互斥，小抖动 / 旋转互斥，两套稳像参数分别回读和应用。夜景、滤波、均衡强度按开关显示，旧固件能力判断保留。

`transport.py`、`tuning.py`、`storage.py`、`checkerboard.py` 及全部 FPGA 源码、ROM、PDS、时钟和引脚不改。连接设置使用原来的 `host/camera_console/settings.json`。界面新增本地照片打开、最近照片、100% / 适应窗口、大图、送入 A/B 和日志保存入口。

## 图像质量工作台

- 左右独立导入原尺寸图像，或在照片页把当前完整照片送入 A/B。支持同步拖动、适应、棋盘特写、1:1、2×、4×、大图对比和来源标记。
- 原尺寸棋盘角点经独立行/列正交直线拟合，给出 RMS、最大值、逐线偏差和偏差曲线。偏差放大只改变诊断标记，不改变照片或测量结果。
- 使用随工程配置的 MTF Mapper 0.7.40 命令行测量 MTF50 / SFR；保留有效斜边筛选、亮度解释设置、缺少结果的明确状态，不把“未测得”写成0。
- 可导出原图、标注图、对比图、曲率曲线、逐线 CSV、MTF CSV/TXT、JSON、HTML 及文字分析。可用真实 Brown 标定生成明确标识的 OpenCV 软件参考；鱼眼标定不混入 Brown 参考。
- 全部分析在后台线程运行；原串口控制继续可用。MTF 临时文件固定写入工程 `work/quality_analysis`，不写 C 盘。

## 当前协议下的对比拍摄

当前 R22 没有 R29 的分源抓拍命令，因此提供“拍摄到 A”“拍摄到 B”，每次都通过原来的、经 CRC 校验的完整帧拍照流程；不会为了测量自动切换算法。

先在“图像处理”设置基准状态，等待回读确认，再拍到 A；再设置需要对比的处理状态并拍到 B。两张图不是同帧，应固定相机、图卡、倍率及光照。也可直接导入已有照片。图片几何处理以照片 `geometry_flags` 回读为准，不能从 A/B 槽位推断“无增强原图”；增强仍遵循当前板卡的原有拍照路径，双视窗仍是显示功能。图像来源和实际几何标记会在工作台显示。

原质量筛选和标定入口继续保留。角点偏差是采样直线度，不是整幅镜头畸变率；不同斜边的 MTF 统计不是一一配对结果。软件参考不会被标成 FPGA 输出。
