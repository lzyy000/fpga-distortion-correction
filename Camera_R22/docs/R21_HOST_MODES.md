# R21：五模式和强度控制

当前为全局直方图均衡化源码修订，推荐入口 `25_打开R21全局均衡化工程.cmd`。唯一PDS仍为 `pnr_camera_r21_modes/camera_1080p30_raw8.pds`。用户自行综合、布局布线、生成位流、下载；本轮仅完成源码、软核ROM和轻量检查。完整算法、GitHub来源和限制见 [R21 GHE](R21_GHE.md)。

## 操作

重新打开 `06_相机上位机.cmd`，连接串口，进入“算法调节”。五个独立开关为矫正、双视窗、滤波、夜景、全局直方图均衡化。滤波/夜景/均衡化开启时显示各自0～100%滑条，关闭时收起。0%像素旁路，100%当前算法完整效果。该页可滚动。上电/KEY0复位全部关闭，KEY1～KEY4不切换模式。

双视窗左侧始终原图，右侧叠加选中的处理；全屏显示所选处理画面。网口保存完整1920×1080 RGB565单幅，包含所选滤波、HE和夜景，不包含分屏和几何矫正。CNP1格式及CRC保持兼容。新HELLO能力 `global_histogram` 对应照片metadata `fpga_frame_ghe_night_follow_host_mode`；它表示位流能力，不代表照片中所有开关均打开。

## 协议

115200波特，每个字节等待TUNE回读。原命令0～100滤波强度，128～228夜景强度，112～127设置低四位模式，240查询。新bit4为HE；248开启、249关闭，保留其他位；低四位命令也保留HE位。

HE强度百分比p先发送241+(p>>4)并等待ACK，低四位l=p&15用229+l（l<11）或250+(l-11)提交并等待ACK。重试每条指令均幂等；不发送无确认的多字节突发。

TUNE v=21新增ghe/ghe_q8/ghe_on/ghe_ready，modes/applied扩为0～31。上位机只在检测到这组扩展后启用HE控件；旧R21四模式、R19/R20强度操作继续兼容。模式与强度在相应帧边界生效，HE建表启动期间旁路，映射表按有效历史帧更新且不在帧中切换。
